1. Multi-source job monitor with LLM scoring

Runs once each morning and only surfaces what appeared today

13data sources
21nodes
1×per day, guaranteed

The problem: checking a dozen job boards by hand every morning, where most of what you see is the same set you already read yesterday. It costs time, and worse, you start ignoring the whole thing.

Decisions I made

  • Remember what was already sent. Surfaced listings are stored in workflow static data and never go to the model again. On a typical day 70 to 80 percent are repeats, so this saves time and API spend at the same time.
  • Handle the source that fights back. One feed returns 403 to plain requests, so that branch routes through headless Chrome instead.
  • Control cost deliberately. The primary model is a free tier. I disabled the internal reasoning budget that was silently eating the output allowance, and wired a paid model as fallback that only runs if the primary fails.
  • Assume the machine is off. If the 8am run doesn't happen it retries every two hours, with a guard so it can still only push once per day.
  • Cheap filters before expensive ones. Roles requiring local work authorisation or a senior title are cut by rules first, so the model never sees them.

2. Freelance gig monitor that drafts the outreach

Finding the gig is the easy half. Writing a tailored opener for each one is the work.

6data sources
5max pushed per day
0auto-submitted

The problem: freelance boards post constantly, but most listings aren't worth bidding on. Budget too low, requires local residency, or it's someone advertising themselves rather than hiring. Filtering is tedious, and after filtering you still have to write a custom opener for each one.

Decisions I made

  • Rules eliminate, the model judges. Obvious non-starters are removed by pattern matching. Only the survivors get scored, which keeps the token bill small.
  • Output something I can actually send. Each surviving gig comes with a 60 to 90 word opener that names what the client needs, cites the closest thing I've genuinely built, and proposes a concrete next step.
  • Never auto-submit. Platforms ban automated bidding and the account is the thing you can't get back. Cold proposals also convert badly, so volume is the wrong goal. The send stays human.
